## Planner decisions

1. **The notice shape is fixed for all ten sites**: `hugel: event %q not recorded: %v`, with
   the event's own name as the first argument. Set in plan 01; this plan applies it verbatim.
2. **The tmux-failure site (`internal/tender/start.go:117`) still returns the tmux error.**
   Its event write failing must not change which error the caller sees — the tmux failure is
   the real one, and it is the one `Start` returns.
3. **`handBack` reports and falls through, exactly as it already does for bd's own failure.**
   `beads.HandBack` must still run when the event write failed; a bead that needs attention
   is more important than the record of it.
4. **`internal/cli/dispatch.go` gets no test.** `handBack` shells out to `bd`, which is not
   available or deterministic in a unit test, and package `cli` has no test harness until
   plan 05. The site is held by a source assertion plus the phase-wide unchecked-site gate
   below. Stated here so the gap is a decision, not an oversight.

## Flagged assumptions (edge probe: unresolved)

The spec-less edge probe classified all three phase requirements as `unclassified`, so all
three stay **unresolved**. This plan's share of SUB-01's:

- **SUB-01 — unresolved.** The edge is *the boundary where the failure report itself cannot
  be delivered*. Assumed: stderr is available and writable at all ten sites. A closed or
  redirected stderr means the failure goes unreported at the moment it happens; plan 04's
  marker is the independent second line of defence, and it too can be unavailable.
- **SUB-01 — unresolved (volume).** A gate against a broken log now prints up to ten notices
  in one run. Assumed acceptable and preferable to a summary line that hides which events
  were lost. No de-duplication is planned.
